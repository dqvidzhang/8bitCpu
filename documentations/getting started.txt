2. What do we want the CPU to do?
    8-bit data path - The CPU works on 8-bit values at a time.

    16-bit instruction - Each instruction is 16 bits wide.

    4 registers: R0 R1 R2 R3 - The CPU has 4 small internal storage spots.

    separate instruction and data memory - One memory holds the program, another holds data.

    multi-cycle FSM - The CPU executes instructions in steps like fetch, decode, execute, writeback.

    flags: Zero, maybe Carry - The CPU keeps small status bits after operations.

3.  What instructions do we need to accomplish this?
        What are instructions?
            Instructions are tiny sets of cammands for your cpu, so basically a cpus langauge
    instructions:

    LDI - value into register

    ADD - add

    SUB - subtracts

    CMP - compares

    LOAD - moves data between reg and ram

    STORE - moves data between reg and ram

    JMP - changes instructions

    JZ - changes instructions

    HLT - ends execution

4. Instruction format
    We will need a way for the cpu to decide which instruction to use in order to do this
    we can use op codes

    we will set 
    bits [15:12] = opcode
        0000 = LDI

        0001 = ADD

        0010 = SUB

        0011 = CMP

        0100 = LOAD

        0101 = STORE

        0110 = JMP

        0111 = JZ

        1111 = HLT

    bits [11:10] = Rd = destination register

    bits [9:8] = Rs = source register

    bits [7:0] = immediate value or memory address
